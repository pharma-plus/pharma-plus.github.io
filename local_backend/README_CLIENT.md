# PHARMA+ LOCAL — Guide client (sans aucune ligne de commande)

## Étape 1 : Installer (une seule fois)
1. Ouvrez le dossier `local_backend/`
2. Double-cliquez sur : `Installer_PHARMA+_LOCAL.bat`
3. Attendez que la fenêtre se ferme toute seule

## Étape 2 : Lancer le serveur (à chaque utilisation)
1. Double-cliquez sur : `Lancer_PHARMA+_LOCAL.bat`
2. Laissez cette fenêtre ouverte (le serveur doit tourner)

## Étape 3 : Utiliser l'application PHARMA+
1. Ouvrez l'application PHARMA+ (Flutter)
2. Allez dans Paramètres → activez "Mode Local"
3. Connectez-vous avec votre email et mot de passe
4. Utilisez normalement : Caisse, Ventes, Catalogue, Stock, Clients, etc.

## Sans Internet
Tout fonctionne hors-ligne. Vos ventes sont enregistrées localement sur votre PC.

## Quand Internet revient
Désactivez le "Mode Local" dans les paramètres pour resynchroniser avec le serveur distant.

## Dépannage
- Si la fenêtre se ferme immédiatement : Node.js n'est pas installé. Installez-le depuis https://nodejs.org
- Si l'application ne se connecte pas : vérifiez que la fenêtre du serveur est ouverte.
